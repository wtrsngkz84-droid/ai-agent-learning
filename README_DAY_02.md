# Day 2：企业制度关键词检索

## 运行

确保终端当前目录是本文件所在的项目目录，然后执行：

```powershell
python search_policy.py
```

运行后可以连续测试：`报销`、`请假`、`密码` 和一个不存在的词；输入 `退出` 结束程序。

## 今天学习的概念

- `Path(...).read_text(...)`：读取文本文件
- `split("\\n\\n")`：按空行切分段落
- 列表推导式：筛选包含关键词的段落
- `if / else`：根据是否找到结果走不同分支
- `enumerate(..., start=1)`：给搜索结果编号
- `while True`：让程序持续接收问题
- `break`：结束循环
- `continue`：跳过本轮，进入下一次输入

## 思考题

1. 为什么程序要把文档切成段落，而不是整篇文档直接输出？
2. 如果用户输入“报销”，程序为什么能找到“报销制度”？
