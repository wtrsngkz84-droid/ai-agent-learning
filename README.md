# Day 1：Python 启动练习

今天的目标：能在终端运行 Python 文件，并看懂变量、输入、条件判断和输出。

## 运行

在此文件夹打开终端后执行：

```powershell
python hello_agent.py
```

输入自己的名字并按回车。

## 你需要看懂的四件事

1. `name = ...`：把用户输入的名字保存到变量 `name`。
2. `input(...)`：在终端向用户提问。
3. `if not name`：当用户没有输入内容时，给一个默认名字。
4. `print(f"...")`：把变量填进文字后输出。
