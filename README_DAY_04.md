# Day 4：最小 RAG 企业制度助手

## 运行

```powershell
.\.venv\Scripts\python.exe rag_policy.py
```

推荐测试问题：

- 出差产生的交通费用应该怎样处理？
- 紧急情况下应该怎样请假？
- 可以把公司的源代码发给朋友吗？
- 公司有没有规定年终奖？

## 程序流程

```text
用户问题
  → 优先使用关键词检索相关制度段落
  → 关键词失败时使用 DeepSeek 进行语义检索
  → 将相关段落作为上下文
  → DeepSeek 根据上下文生成回答
  → 显示答案和引用制度
```

## 与完整 RAG 的差距

当前先使用关键词检索，失败后由 DeepSeek 从少量制度中选择相关段落。这个方法能理解近义表达，但会增加一次 API 调用，也不适合大量文档。后续会加入 Embedding 和向量数据库，完成可扩展的语义检索。
